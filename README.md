# 圖像辨識誤差並回傳機器手臂座標程式碼
# Vision Based Robotic Calibration

經由圖像辨識技術辨識物件與標準線的誤差後，對原始座標做誤差調整，再回傳機器手臂程式碼。

[![demo.mp4](https://i.ytimg.com/an_webp/E3Ua950lhXc/mqdefault_6s.webp?du=3000&sqp=CPKno88G&rs=AOn4CLAklYFVueQAGZB0ej3cvJVqB_vGHw)](https://youtu.be/E3Ua950lhXc "demo.mp4")

## 開發環境

- Ubuntu **24.24** 64bit
- Python **3.8.19**
- opencv `4.10.0`
- numpy `1.23.3`
- ezdxf `1.1.4`

---

## 如何執行

進入此目錄，並且在終端機中輸入以下指令。

```bash
python Run.py
```
