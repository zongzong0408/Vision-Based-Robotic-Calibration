# xArm 6 視覺自動化測量與模擬系統

本專案基於 **PyBullet** 物理引擎與 **OpenCV** 影像處理技術，模擬機器手臂（xArm 6）搭載虛擬攝影機進行工件辨識與尺寸測量的自動化流程。  
系統整合了多執行緒終端機介面，支援即時監控與手動控制模式。

## 核心功能

### 1. 物理模擬環境 (PyBullet)

* **多重作業平台**：配置基礎平台 (Base)、合格品平台 (Good) 與不良品平台 (Poor)。
* **物理特性模擬**：精確設定重力 (Gravity)、摩擦力 (Friction) 與碰撞偵測。
* **除錯視覺化**：即時繪製 XYZ 座標軸與攝影機視線 (Watch Target) 除錯線。

### 2. 機器手臂控制 (xArm 6)

* **平滑路徑規劃**：透過 `robot_move_smoothly` 實作關節插值，確保手臂移動平穩。
* **夾爪控制系統**：支援並行控制夾爪的張開與閉合動作。
* **軌跡執行**：內建自動化測量路徑，支援循序執行多個目標點。

### 3. 虛擬相機與視覺辨識 (OpenCV)

* **眼在手隨 (Eye-in-Hand)**：相機綁定於手臂末端連桿，隨手臂移動。
* **即時影像擷取**：同步獲取 RGB 影像與深度資訊。
* **自動尺寸測量**：
* 利用 `findContours` 與 `boundingRect` 偵測物件輪廓。
* 根據相機 FOV 與深度 (Depth) 計算物件的真實長度與寬度。

### 4. 互動式監控介面 (UI)

* **多執行緒設計**：採用 `threading` 與 `queue` 分離模擬核心與使用者輸入。
* **模式切換**：
* **監控模式 (Monitor)**：顯示即時關節弧度、測量數據與任務進度。
* **手動模式 (Manual)**：提供指令介面供開發者手動調整手臂姿態。

### 安裝必要套件

```bash
pip install pybullet opencv-python numpy
```

### 執行模擬

```bash
python run.py
```

## 控制指令

於程式執行後的終端機介面輸入以下按鍵：

| 按鍵 | 功能 |
| --- | --- |
| **M** | 返回主選單 |
| **1** | 進入 **監控模式** (查看測量數據與弧度) |
| **2** | 進入 **手動模式** (控制手臂移動) |
| **3** | 安全關閉系統並結束程式 |
| **H** | (手動模式下) 查看手動操作指令說明 |
| **Q** | (手動說明下) 返回上一頁 |
| **I** | (PyBullet 視窗中) 切換預設攝影機視角 |

## 程式碼結構說明 `**run.py**`

* `initialize_environment_simulation()`: 初始化模擬器、重力與基礎平面。
* `load_robot()`: 載入 xArm 6 URDF 模型並設定初始姿態。
* `load_camera()`: 將攝影機物體透過固定約束 (Fixed Constraint) 綁定至手臂末端。
* `capture_camera_image()`: 計算視圖矩陣並擷取虛擬鏡頭畫面。
* `calculate_image_contour()`: 核心視覺演算法，負責像素與真實物理單位的換算。
* `display_panel()`: 負責維護終端機 UI 狀態機。
