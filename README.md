# xArm 6 視覺引導自動化校準與量測系統 v2.0

本專案是一個整合 **PyBullet 物理模擬引擎** 與 **OpenCV 電腦視覺** 的進階機器人應用程式。  
其核心目標是驅動 xArm 6 機器手臂，利用安裝於末端執行器（End-effector）的相機，對工件進行多角度自動化尺寸量測與品質判定。  

## 🚀 核心技術優化

### 1. 進階運動控制系統

* **逆運動學 (Inverse Kinematics, IK)：** 支援透過 `robot_move_to_xyz` 函式，直接輸入目標世界座標 `(x, y, z)`，系統將自動計算各關節所需的弧度。
* **平滑軌跡插值：** 利用 `utility_trajectory_smoothly` 線性插值技術，在離散的目標點之間生成平滑過渡，降低物理模擬中的震動。
* **穩定性偵測：** 內建 `ROBOT_STABLE_FRAME_WAIT` 機制，確保機器人完全停止震盪後才進行影像擷取，提升量測精度。

### 2. 視覺量測演算法 (Computer Vision)

* **色彩分割 (Color Masking)：** 不同於基礎的二值化，`run.py` 採用 BGR 顏色空間過濾（`cv2.inRange`），可針對特定顏色的工件（如黃色）進行精準提取。
* **物理空間映射：** 透過相機視野角 (FOV) 與即時深度資訊（Depth），將像素距離動態轉換為實際物理單位（公尺）。
* **多角度量測：** 系統會自動執行不同平面的觀測（+XY 面與 -XZ 面），以獲得工件的完整 3D 尺寸數據。

### 3. 強健的多執行緒架構

* **並行處理：** 使用 `threading` 將「物理模擬主迴圈」與「使用者終端機介面」分離，確保操作時模擬不中斷。
* **執行緒安全：** 透過 `threading.Lock` 保護關鍵變數（如軌跡數據、關節狀態），防止多執行緒存取衝突。

## 🤖 狀態機流程說明 (State Machine)

程式啟動後，機器人將依照 `state` 變數自動執行以下階段：

1. **State 1 (初始化)：** 手臂移動至觀測起始點 `PXY_POINT`。
2. **State 2 (+XY 面觀測)：** 相機對準工件俯視圖，計算 X、Y 軸長度，並等待數值穩定。
3. **State 3 (-XZ 面觀測)：** 手臂變換姿態觀測工件側面，計算高度資訊，完成 3D 尺寸校準。

## ⌨️ 互動控制指令

在終端機介面中，您可以輸入以下指令進行操作：

### 模式切換

* `1`：進入 **監控模式 (Monitor)**，即時檢視工件測量數值與誤差。
* `2`：進入 **手動模式 (Manual)**，直接控制關節或座標。
* `3`：退出系統。
* `M`：返回選單。
* `R`：手動重新整理 (Refresh) 終端機畫面。

### 手動模式特有指令

* **座標控制：** 輸入 `(x, y, z)` (例如：`(0.2, 0.1, 0.3)`)，手臂將透過 IK 移動至該位置。
* **關節控制：** 輸入 `關節索引 弧度` (例如：`5 1.5`)，精確調整特定馬達位置。

## 🛠️ 開發環境需求

* **作業系統：** Windows 10/11, Ubuntu 20.04+ 或 macOS。
* **語言：** Python 3.8+
* **核心套件：**
```bash
pip install pybullet opencv-python numpy
```


* **資源檔：** 請確保專案目錄下包含 `xarm/xarm6_with_gripper.urdf` 機器人模型檔。

---

## 📂 程式碼目錄導覽 (`run.py`)

* `initialize_environment_simulation`: 配置模擬步長 (`1/1000s`) 與重力環境。
* `load_camera`: 建立固定約束 (Fixed Constraint)，將虛擬相機鎖定在手臂第 6 連桿。
* `calculate_image_contour`: 整合 OpenCV 濾波、輪廓偵測與單位轉換的核心函式。
* `display_panel`: 複雜的終端機 UI 邏輯，負責處理不同模式下的畫面輸出。
* `utility_trajectory_smoothly`: 軌跡預處理工具，提升運動質感。
